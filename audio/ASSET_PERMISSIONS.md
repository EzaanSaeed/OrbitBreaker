# Audio asset permissions and licensing

## GTA V WASTED death recording

On 2026-11-14, the Orbit Breaker project maintainer explicitly confirmed
permission to include and distribute `audio/sfx/gta-v-death-sound-effect-102.mp3`
in this project's private GitHub repository. This records the maintainer's
project-specific permission; it is not a claim that Rockstar Games or another
rights holder granted a general license, nor that the recording is open source.
Do not reuse or publish the recording outside this private project without
separate rights-holder permission.

The source audio package labels this recording third-party copyrighted material
and previously instructed the project not to bundle it without permission. The
maintainer has since confirmed permission for private-repository distribution.

## Other selected audio

The source package reports that selected sounds came from Kenney CC0 packs, but
does not include individual asset provenance or license files. It also says
the background music and laser files were supplied by the user and their license
metadata was not independently verified. Preserve the source package's README
with the original materials and verify any missing provenance before public
distribution.
